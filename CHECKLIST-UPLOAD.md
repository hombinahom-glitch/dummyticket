## Quality Check Sebelum Upload:

### ✅ Technical Requirements
- [ ] Semua foto sudah di-compress (< 500KB untuk photo, < 800KB untuk screenshot)
- [ ] Resolusi minimal 1600x1200px untuk landscape
- [ ] Format: JPG atau PNG
- [ ] Nama file sesuai dengan yang tertera di checklist (case-sensitive!)

### ✅ Visual Quality
- [ ] Lighting baik, tidak over/under exposed
- [ ] Focus tajam
- [ ] Komposisi bagus
- [ ] Color grading konsisten dalam satu kategori
- [ ] Tidak ada watermark atau copyright orang lain

### ✅ Organization
- [ ] Semua foto di folder yang benar
- [ ] Backup original files tersimpan
- [ ] Folder structure sesuai README-IMAGES.md
